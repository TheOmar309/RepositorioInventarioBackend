# 📦 API RESTfull - Sistema de Gestión de Inventario (Backend)

Este proyecto es el backend de un Sistema de Inventario desarrollado en **Spring Boot**, diseñado para exponer una API RESTful completa que gestiona las tablas de Categorías y Productos. 

Este repositorio forma parte de la entrega para la materia de Desarrollo de Aplicaciones Distribuidas.

## 🛠️ Tecnologías Utilizadas
*   **Java** 
*   **Spring Boot** (Web, Data JPA)
*   **Base de Datos:** (Ej. MySQL / PostgreSQL)
*   **Gestor de dependencias:** Maven / Gradle

## ✨ Funcionalidades (CRUD Completo)
La API permite realizar todas las operaciones básicas para ambas entidades:
1.  **Consultar:** Obtención de todos los registros y búsquedas por ID.
2.  **Crear:** Inserción de nuevas categorías y productos.
3.  **Modificar:** Actualización de datos existentes.
4.  **Eliminar:** Borrado de registros.
